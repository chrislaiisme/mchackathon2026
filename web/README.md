# web/

Demo 用的 Web 前端。

負責線：線 5｜Web 前端與 Demo
對應功能：FR-001 Need Input；FR-009 中的所有畫面；FR-003、FR-007、FR-008 對應的畫面

## 畫面

- 需求輸入與參考圖
- 意圖面板（使用者原話與系統推斷分開）
- 圖片選擇題：以上皆非、自由輸入、圖片未完成先顯示文字
- 商品卡片、推薦理由、概念圖
- 分維度評分
- 輪次對比與符合度分數
- Agent 活動紀錄
- 網路失效時的重播模式

## 介面

- 需要：每一輪的完整結果（線 4）
- 提供：使用者的評分、選擇與回饋（線 4）
