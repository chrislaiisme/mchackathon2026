# evals/

量化驗證。驗證流程與 live 流程共用同一套系統；所有結果都要標明是自動化模擬，不是真人測試。

| 資料夾 | 驗證項目 | 負責線 |
|---|---|---|
| `intent/` | 意圖抽取準確率（30–50 句測試集） | 線 1 |
| `simulated_user/` | 模擬使用者：相似度收斂、屬性還原率 | 線 1 |
| `recommendation/` | 三種推薦做法比較 | 線 2 |
| `choice_images/` | 選項圖檢查通過率 | 線 3 |
| `results/` | 產出的圖表，供 README 與簡報使用 | 各線 |

驗證所需的生圖要等第一輪端到端打通後立即開始跑，並在第一天跑完（PRD 附錄 A.7）。
